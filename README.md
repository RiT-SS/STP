# 时空之门 · STP

《时空之门》的 Unity 可编辑工程，基于作者保留的编译版本恢复，包含后续修复与玩法调整。

## 打开工程

- Unity 版本：**2021.3.21f1c1（中国版）**。
- 在 Unity Hub 中添加此仓库根目录，等待首次资源导入完成。
- 打开 `Assets/Scenes/StartMenu.unity`，点击编辑器播放按钮。
- 仓库包含 `Assets`、`Packages`、`ProjectSettings` 和全部资源 `.meta` 文件；Unity 会自动生成缓存目录。
- 窗口可以调整大小，游戏画面保持 5:2 比例，空余区域显示黑边；主菜单、选人、游戏和记录页统一缩放。

## 编译 Windows 版

使用 Unity 的 `-batchmode -quit -projectPath <工程目录> -executeMethod BuildPlayableRelease.Run -releasePath <新的输出目录>` 参数，可编译 Windows 64 位发行版。
输出目录需要尚不存在；双击输出中的 `时空之门.exe` 即可游玩。发送给玩家时应保留整个输出文件夹，并排除个人的 `SaveData` 目录。

## 操作

| 按键 | 功能 |
| --- | --- |
| W / ↑ | 跳跃、二段跳；盗贼在下落时按住可滑翔 |
| S / ↓ | 滑铲、加速下落 |
| A | 机器人冲刺 |
| Esc | 暂停 / 继续 |
| R | 重新开始 |

## 角色与玩法

- **探险家 爱丽丝**：致命伤害时自动复活，复活冷却 60 秒。
- **盗贼 燕子**：下落时可以滑翔。
- **机器人 伯特**：冲刺时长 3 秒，冷却 40 秒；随平台高度移动。
- 护盾、磁体的持续时长配置均为 5 秒。原有道具点独立有 25% 概率刷新道具。
- 每局前三张场景固定为古代（AC）→战争（WW）→中世纪（MA）；之后在当前场景之外的两种场景中随机选择。
- 传送门战利品门槛依次为 10、12、14、16……。右上角显示本关收集进度，显示值达到需求后封顶，后台继续累计额外战利品。
- 游戏记录保留整局距离与三类战利品总数，按距离、开始时间排序，保留前 20 条。

## 工程内容

| 目录 | 内容 |
| --- | --- |
| `Assets/Scenes` | 主菜单、选人界面与三个游戏场景 |
| `Assets/Scripts/Assembly-CSharp` | 游戏逻辑与恢复的脚本 |
| `Assets/Editor` | 编辑器辅助工具和恢复过程中的验证工具 |
| `Assets` 其余目录 | 场景、预制体、动画、图片、音频、字体与材质 |
| `Packages` / `ProjectSettings` | 依赖和 Unity 项目配置 |

本地缓存、日志、临时文件、个人游戏记录、Unity 安装文件与编译输出不纳入 Git。可运行版本可以另行发布到 GitHub Releases。

编辑器辅助检查会生成独立测试记录和报告。日常游玩从 `StartMenu` 开始即可。
